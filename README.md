# Système de vote électronique local

Application de vote développée en Java, avec une interface JavaFX et une base de données MySQL. Projet de groupe réalisé à l'Université Amadou Mahtar Mbow en 2026.

## Fonctionnalités

- Authentification des électeurs
- Un seul vote par personne
- Dépouillement automatique
- Publication des résultats
- Espace administrateur

## Technologies

Java, JavaFX, MySQL

## Lancement

1. Installer Java, JavaFX et MySQL.
2. Créer la base de données MySQL du projet.
3. Renseigner dans le code les identifiants de connexion à MySQL.
4. Ouvrir le projet dans un environnement Java et lancer l'application.
